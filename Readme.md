# LUMORA — Luxury Interior Design Website

A modern and elegant luxury interior design website built using **HTML5 and CSS3**. LUMORA features a premium design aesthetic with sophisticated colors, beautiful interior photography, modern layouts, and smooth hover effects.

## Preview

LUMORA is designed for a luxury interior design studio, showcasing creative spaces, architectural projects, and professional design services.

## Features

- Modern and elegant user interface
- Premium Forest Green, Cream, and Bronze color theme
- Professional navigation bar
- Full-screen hero section with background image
- About Us section with statistics
- Featured projects portfolio
- Interior design services section
- Client testimonials
- Contact form UI
- Professional footer
- Smooth scrolling and hover effects
- Responsive layout for mobile, tablet, and desktop

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- CSS Flexbox
- CSS Variables
- CSS Animations
- CSS Media Queries
- Google Fonts
- Unsplash Images

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Run the project using Live Server.
5. Explore the LUMORA website in your browser.
